# Support

M365Intelligence is maintained as an open-source project. Community support is best-effort and is provided through GitHub Issues and Discussions when enabled for the repository.

- Use issues for reproducible bugs and feature proposals.
- Use discussions for deployment questions, implementation ideas, and how-to topics.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose a vulnerability or tenant data publicly.

There is no service-level agreement, managed tenant monitoring, or warranty in this repository. Organizations deploying it are responsible for their own tenant permissions, compliance assessment, backup and restore strategy, patching, and operational controls.
